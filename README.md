# Iron Arena online

1. Save your current game file as `original.html` in this folder (next to server.js).
2. `npm install`
3. `npm run patch`   (creates public/index.html, the online version)
4. `npm start`       (open http://localhost:3000, or deploy to any Node host)

Accounts are stored in `data/users.json` (set DATA_DIR to a persistent disk when hosting).
